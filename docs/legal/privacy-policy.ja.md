# Fumi プライバシーポリシー

_最終更新日: 2026-06-13_

Fumi（以下「本アプリ」）は、**[氏名／事業者名]** が提供する macOS・Windows・Linux 向けデスクトップメールクライアントです。本ポリシーは、本アプリが扱うデータとその取り扱いを説明します。

## 概要

本アプリは**ローカルファースト**です。メール・カレンダー・連絡先・アカウント認証情報は**お使いの端末内にのみ**保存されます。**当方はユーザーデータを受け取るサーバーを一切運用せず、本アプリにアナリティクスやテレメトリは含まれません。** データは、接続先サービス（Google、ご利用の IMAP/SMTP プロバイダ）と、オプトインした場合のみご自身の API キーで設定した AI プロバイダにのみ送信されます。有料ライセンスの検証のため、本アプリはライセンスキー（およびそれ以外のユーザー情報は含まない）を決済プロバイダへ送信します。詳細は[ライセンス検証](#ライセンス検証)をご覧ください。

## アクセスする情報

Google アカウント接続時、本アプリは以下のスコープを要求します。

- **Gmail**（`gmail.modify`・`gmail.compose`・`gmail.send`）— メールの閲覧・整理・下書き・送信のため。
- **Google カレンダー**（`calendar`）— 予定の表示・作成のため。
- **基本プロフィール**（`userinfo.email`・`userinfo.profile`）— メールアドレス・氏名・アバターの表示のため。

IMAP アカウント接続時は、入力されたメールボックスの認証情報とサーバー設定を保存します。

## データの利用と保存

- アクセスした全データ（メッセージ・スレッド・ラベル・連絡先・添付ファイル・予定・OAuth トークン）は、端末内の SQLite データベース（`fumi.db`）に**ローカル保存**されます。
- 本アプリは端末から Google API および設定された IMAP/SMTP サーバーと**直接**通信します。これらのデータが当方の運用するサーバーを経由することはありません。
- OAuth のアクセストークン・リフレッシュトークンはローカルに保存され、ご自身の Google へのリクエスト認証のためにのみ使用されます。

## AI 機能（任意・オプトイン）

本アプリには任意の AI 機能（スレッド要約・スマート返信・受信トレイへの質問・タスク抽出）があります。これらは、機能を有効化し、選択したプロバイダ（Anthropic・OpenAI・Google）の **ご自身の API キー** を設定した場合にのみ動作します。

AI 機能の利用時、該当するメッセージ内容は端末から、設定した AI プロバイダへ**直接**送信され、**当該プロバイダ**のプライバシーポリシー・規約が適用されます。当方はこの内容を受信・保存・処理しません。AI 機能を使用しない場合、メッセージ内容が AI プロバイダへ送信されることはありません。

## Google API サービスのユーザーデータポリシー（限定的使用）

本アプリによる Google API から受け取った情報の利用は、[Google API サービスのユーザーデータに関するポリシー](https://developers.google.com/terms/api-services-user-data-policy)（**限定的使用** の要件を含む）を遵守します。具体的には次のとおりです。

- Google ユーザーデータは、端末上で**本アプリのユーザー向け機能を提供・改善する目的にのみ**使用します。
- Google ユーザーデータは、ユーザーが指示した機能の提供に必要な場合（設定した AI プロバイダへのメッセージ送信等）、適用法令の遵守、または事前に通知される合併の場合を除き、**第三者に転送しません**。
- Google ユーザーデータを**広告目的で使用しません**。
- 明示的な同意がある場合、セキュリティ・法的理由で必要な場合、または集計・匿名化された場合を除き、**人間が** Google ユーザーデータを**閲覧しません**。

## ライセンス検証

本アプリは有料アプリです。ライセンスの有効化と検証のため、本アプリはライセンスの有効化時およびアプリ起動時（ライセンスが有効か確認するため）に、**ライセンスキー**と生成した**インストール識別子**を、当方のライセンス・決済プロバイダである **Lemon Squeezy**（当方のリセラー兼 Merchant of Record）へ送信します。このリクエストに含まれるのは**ライセンスキーとインストール識別子のみ**で、メール・連絡先・メッセージ内容は一切含まれません。これは [Lemon Squeezy のプライバシーポリシー](https://www.lemonsqueezy.com/privacy)に従います。当方はこのサーバーを運用しておらず、この目的で端末外に出るのはライセンスキーとインストール識別子のみです。

## データの共有

当方はデータの販売・貸与・共有を行いません。外部送信は (1) アカウントを動作させるための Google および IMAP/SMTP プロバイダへの送信、(2) 任意で設定した AI プロバイダへの送信、(3) 上記のとおりライセンスキー検証のための当方のライセンスプロバイダ（Lemon Squeezy）への送信のみです。

## データの保持と削除

全データがローカル保存されるため、**管理権はユーザーにあります**。

- 接続済みアカウントを本アプリ内で削除すると、ローカル保存データが削除されます。
- 本アプリをアンインストールし `fumi.db` を削除すると、ローカル保存データはすべて削除されます。
- [myaccount.google.com/permissions](https://myaccount.google.com/permissions) からいつでも本アプリの Google アカウントへのアクセスを取り消せます。

## セキュリティ

データは端末内に保存され、OS のユーザーアカウント管理で保護されます。Google や AI プロバイダとの通信は HTTPS/TLS を使用します。Google OAuth は PKCE フローを使用します。
